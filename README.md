# UnTile Civ6 Tileset

Tileset for [Unciv](https://github.com/yairm210/Unciv) in Civ6 Style
(Compatible with Civ6 Mod)

WORK IN PROGRESS

## Installation

1. Visit Mods
2. Filter for "Untile"
3. Download the Until Civ6 Tileset mod
4. Enable the "Permanent audiovisual mod" option

## Usage

1. Open the Options menu
2. Visit the Display tab
3. Select the "UnTile" Tileset

## Recommendations

- Use [Civ 5 Icons](https://github.com/vegeta1k95/Civ-5-Icons) for *Vanilla* or *Gods & Kings*
- Use [Civ6 Icons](https://github.com/EmperorPinguin/Civ6-Icons) for the [Civ6 Mod](https://github.com/EmperorPinguin/Civ6-mod)
